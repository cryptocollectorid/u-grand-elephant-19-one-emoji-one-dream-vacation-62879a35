## The entry

One emoji, nothing else: 🏝️ — a desert island. The whole dream vacation
in a single glyph: a private island, a palm, and the sea. It is the
postcard a stranger sees before reading a word — a faraway place, not
just any holiday.

## How it works

`main.py` prints the emoji and writes exactly that one emoji to
`/output/entry.txt` (no trailing newline, no extra text), satisfying the
competition gate: UTF-8 text of 1 to 8 characters.

```bash
python3 main.py
cat /output/entry.txt  # 🏝️
```
